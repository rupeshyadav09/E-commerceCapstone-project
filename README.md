# 🛒 E-commerce Capstone Project

A full-stack E-commerce web application designed to provide users with a smooth and user-friendly online shopping experience. The project includes a modern frontend, backend APIs, and database integration.

## 🚀 Features

- 🏠 **Home Page** – Browse products with a clean and responsive interface.
- 🔐 **User Authentication** – Login and registration functionality.
- 🛍️ **Product Listing** – Explore and view available products.
- ❤️ **Wishlist** – Save your favorite products.
- 🛒 **Shopping Cart** – Add, remove, and manage products.
- 📦 **Product Details** – View individual product information.
- 📱 **Responsive Design** – Optimized for different screen sizes.
- ⚙️ **Backend API** – Handles application logic and data operations.
- 🗄️ **Database Integration** – Stores application data.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/rupeshyadav09/E-commerce-Capstone-project.git
```

### 2. Navigate to the Project

```bash
cd E-commerce-Capstone-project
```

### 3. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 4. Start Frontend

```bash
npm run dev
```

### 5. Install Backend Dependencies

Open another terminal:

```bash
cd backend
npm install
```

### 6. Configure Environment Variables

Create a `.env` file inside the backend folder and add your required configuration:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

Add any other environment variables required by your backend.

### 7. Start Backend

```bash
npm run dev
```

*Use the actual start script defined in your backend package.json.*
